# Customer Churn Prediction

End-to-end Data Science project that predicts whether a customer is likely to churn using machine learning.

## Features
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Feature engineering
- Model training (Logistic Regression, Random Forest)
- Model evaluation
- Feature importance visualization
- Streamlit web application
- Model deployment ready

## Tech Stack
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Streamlit
